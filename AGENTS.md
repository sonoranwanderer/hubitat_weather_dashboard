# Agent Instructions

When the user requests a code change in this git repository:

1. Create a new branch before making changes.
2. Implement the requested change.
3. Run relevant tests or checks.
4. Commit the changes with a clear commit message.
5. Ensure commits are signed. Do not create unsigned commits.
6. Push the branch.
7. Open a pull request.
8. Monitor the pull request for code review comments and CI failures.
9. Address all PR code review comments.
10. Resolve every PR review thread whether code changes were made or not.
11. Use follow-up commits for comments that require code changes.
12. Re-run relevant checks after fixes.
13. Do not merge the PR unless explicitly asked.
