Code and supporting configuration to build an Ecowitt HP2561 like hubitat Dashboard

Each javascruipt file represent a tile to be used on the dashboard creating one of 
the core display elements of the Ecowitt HP2561

The javscript reads data from other tiles on the dashboard that expose raw one of:
* Weather device attribute
* Hub variable
* Collection of HTML formated data from a weather device
* Other useful information from non device or hub variable sources
