# Legacy v1 Snapshot

This folder preserves the original tile-based dashboard experiment and its companion Hubitat app/driver files.

## Contents

* `dashboard/` contains the standalone JavaScript tiles used by the legacy dashboard.
* `hubitat/` contains the older Hubitat app/driver pair that powers the pressure tendency workflow.
* `README.md` documents the snapshot only.

## Notes

* The JavaScript files are intended to be loaded through the Hubitat dashboard injector workflow used by the v1 experiment.
* The pressure tendency app/driver pair is kept here for reference alongside the other legacy dashboard pieces.
* This folder is historical and should be kept consistent with its own files, not with the root implementation.
